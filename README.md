# FutureOS

A futuristic web-based operating system dashboard built with React + TypeScript.

## Features
- System bar with live clock
- App launcher
- Terminal app
- Notes app
- Modular architecture for adding more apps

## Run in GitHub Codespaces
1. Open the repo in Codespaces
2. run: `npm run dev`
3. Open the forwaded port

## Build
`npm run build`
